Communiquer avec les adhérents

E-mails via OVH · SMS depuis votre iPhone.

Le modèle remplit l’objet et le message. Vous pouvez ensuite les adapter et choisir les destinataires avant l’envoi.

La saison sélectionnée s’applique. La recherche dans le tableau ne limite pas les destinataires : le groupe choisi ici fait foi. Les coordonnées partagées sont regroupées.

Chaque adresse reçoit un e-mail individuel depuis contact@km16.fr. Réservé aux informations pratiques du club. Gardez cette page ouverte pendant l’envoi ; vous pouvez le mettre en pause et le reprendre depuis l’historique.

Les SMS s’ouvrent dans Messages sur votre iPhone ; vous validez chaque envoi avec votre forfait Orange. Un envoi groupé peut rendre les numéros visibles et utiliser un MMS ou un iMessage selon vos réglages. La facturation et les limites dépendent de votre forfait. Pour les mineurs, vérifiez que les coordonnées sont celles du représentant légal.
