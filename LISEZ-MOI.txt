KM16 – Référencement du domaine actuel
Le site public de référence est https://app.km16.fr/.
Les anciennes adresses https://kravmaga16.github.io/km16-app/ redirigent vers ce domaine ; leur exclusion « Page avec redirection » est normale dans Google Search Console.
Dans Search Console, utiliser la propriété https://app.km16.fr/ (ou la propriété de domaine km16.fr), soumettre https://app.km16.fr/sitemap.xml puis inspecter https://app.km16.fr/ pour demander son indexation.
Conserver la redirection GitHub Pages et le HTTPS obligatoire dans Settings > Pages.
Les pages d’administration et les parcours privés restent exclus de l’indexation.
